# 东方云笺 UI 重设计（2026-08-12）

## 方向

弃用上一版霓虹夜航像素风，改为贴近中文用户习惯的「东方云笺」风格：
宣纸暖底、墨色文字、朱砂红主色、青瓷绿辅色、鎏金点缀。默认浅色，
同时保留适配中文用户的深色模式。

## 设计令牌

- 背景：暖纸色 `hsl(38 33% 96%)`，深色模式为墨蓝黑。
- 主色：朱砂红 `#C2452F`（深色模式提亮为 `#E0654A`）。
- 辅色：青瓷绿 `#3D7A68`，用于状态、成功与选中反馈。
- 点缀：鎏金 `#C08A2D`，用于徽章、印章与渐变收尾。
- 字体：正文使用 `PingFang SC / Microsoft YaHei / HarmonyOS Sans SC /
  Noto Sans CJK SC` 系统中文栈，不再加载像素字体。
- 圆角：面板 12px、按钮/输入框 8-12px，避免大面积胶囊形。

## 布局与交互

- 首页：左侧竖排朱砂分隔线与大标题，右侧实时收件箱预览；
  下方四张功能卡，桌面与移动端均无横向溢出。
- 顶栏：品牌 + 居中导航 + 语言/主题/登录操作；移动端增加菜单按钮。
- 登录：印章式 Logo + 卡片化表单，登录/注册分段切换。
- 邮箱：三栏面板布局，选中态使用朱砂/青瓷浅色底与描边，
  去除霓虹光晕，信息密度与可读性优先。
- 个人中心与分享页：统一 `panel-card` 面板，配置区块使用同一种视觉语言。

## 品牌与 PWA

- Logo 保留「M 像素信封」方向，改为朱砂印章 + 鎏金印章点的新配色。
- 重新生成 `public/icons` 与 `app/favicon.ico`。
- 更新 `manifest.json` 背景色与主题色。

## 验证

- `pnpm lint` 通过（仅保留既有 warning）。
- `pnpm build` 通过。
- 本地 Playwright 截图验证首页/登录/分享错误页桌面与移动端无横向溢出。
