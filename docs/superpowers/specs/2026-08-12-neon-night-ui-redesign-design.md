# mail.59pk.net 霓虹夜航 UI 重构设计

日期：2026-08-12
状态：待用户确认

## 目标

弃用 mail.59pk.net 现有前端 UI，在保留 Next.js App Router、Tailwind CSS、Radix UI、next-intl 架构和全部功能逻辑的前提下，重做整套前端界面，并同步重做 Logo。

本次只改 `app/` 前端层与静态资源，不修改 API 路由、数据库、认证、Worker、部署脚本。

## 设计方向

新 UI 命名为“霓虹夜航”（Neon Night），以深色太空为基底，青蓝与品红霓虹为视觉主角，保留 mail.59pk.net 的“萌”基因，但整体气质更酷、更有现代科技感。

## 设计系统

### 颜色

| Token | 色值 | 用途 |
| --- | --- | --- |
| Space Black | `#05070D` | 页面主背景 |
| Deep Space Blue | `#0B1220` | 面板背景 |
| Nebula Blue | `#101B2E` | 卡片背景 |
| Neon Cyan | `#22D3EE` | 主强调色、主按钮 |
| Neon Magenta | `#E879F9` | 次强调色、选中状态 |
| Signal Lime | `#A3E635` | 成功、在线、新邮件状态 |
| Text Bright | `#E5EAF2` | 主文字 |
| Text Muted | `#7E92B0` | 次要文字 |

面板、卡片统一使用半透明深蓝底加 1px 霓虹描边，配合轻微青色/品红光晕。

亮色模式使用同组强调色，背景改为接近白色的浅色：页面背景 `#F5F8FC`、卡片背景 `#FFFFFF`、主文字 `#0F172A`、次要文字 `#5B6B84`。

### 字体

- 品牌名、大标题：继续使用项目内置的 Zpix 像素字体，配合霓虹渐变。
- 正文、数据、表单：系统无衬线字体，保证可读性。
- 状态标签、代码片段：等宽字体。

### 质感

- 背景叠加细网格、星点与极淡扫描线。
- 卡片采用 `8px-12px` 圆角，按钮主用圆角胶囊，辅助按钮保留直角细节。
- 关键按钮、当前状态带霓虹光晕。
- 暗色为默认主题，同时保留亮色模式；亮色模式使用同组强调色，背景改为接近白色的浅色。

## Logo：M 像素信封

新 Logo 以“像素信封 + 字母 M”为核心：

- 信封主体为圆角矩形，青色霓虹描边。
- 信封折线使用青色。
- 字母 M 由像素方块拼成，使用品红与青色混排，强化像素感。
- 保留 mail.59pk.net 品牌名，品牌文字使用 Zpix 字体和青蓝到品红的渐变。

同步更新：

- `app/components/ui/logo.tsx` 中的 SVG Logo。
- `public/favicon.ico`。
- `public/icons/icon-192x192.png`、`public/icons/icon-512x512.png`。
- PWA `public/manifest.json` 中的品牌色。

## 页面重构

### 首页 `/`

- 全屏深空背景，细网格与星点。
- 顶部导航：Logo、首页/邮箱/个人中心入口、语言切换、主题切换、登录与开始使用按钮。
- Hero 区：左侧渐变大标题与功能描述，右侧“实时收件”模拟面板，展示新邮件卡片。
- 功能区：隐私保护、实时收信、灵活期限、多语言四个霓虹标签。
- CTA：创建临时邮箱、查看功能。
- 页脚：品牌信息、项目链接、版权。

### 登录页 `/login`

- 居中玻璃卡片，带霓虹光环。
- 品牌 Logo 与欢迎文案。
- 邮箱、密码输入框。
- 登录主按钮，GitHub / Google 快捷登录按钮。
- 加载、错误、无权限状态沿用新设计系统。

### 邮箱主界面 `/moe`

- 三栏布局：左侧邮箱列表，中间邮件列表，右侧邮件详情。
- 当前邮箱、当前邮件使用品红或青色霓虹高亮。
- 新邮件、未读状态使用信号绿。
- 新建邮箱、发送、分享、删除等对话框统一重绘。
- 支持移动端单栏切换，保持现有交互逻辑。

### 个人中心 `/profile`

- 两栏布局：左侧用户身份卡片，右侧设置面板。
- 设置分区：邮箱域名、默认角色、网站配置、SMTP 发件服务、Webhook、API Key、用户管理。
- 状态开关、表单控件全部使用新设计系统。

### 分享页 `/shared/*`

- 只读邮箱与邮件详情页复用邮箱界面设计系统。
- 保留无权限、过期、错误页面样式。

## 组件调整

- 重写 `app/components/ui/logo.tsx`。
- 重写 `app/components/layout/header.tsx`、`brand-header.tsx`、浮层语言切换。
- 重写首页相关组件：`home/action-button.tsx`、`home/feature-card.tsx`，新增实时收件预览组件。

- 通过 `app/globals.css` 更新设计令牌、霓虹工具类，尽量让基础组件自动跟随主题。

## 文案

首页与关键页面文案可随新 UI 微调，但保持各语言版本同步，不改变功能语义。

## 非目标

- 不修改后端 API、数据库表结构、认证流程、邮件 Worker。
- 不改变页面路由与数据结构。
- 不引入新的 UI 框架，沿用 Tailwind + Radix。

## 验收

1. `pnpm lint` 无新增错误。
2. `pnpm dev` 可正常启动，主要页面可访问。
3. 桌面与移动端截图检查无文字溢出、元素重叠。
4. 亮色、暗色主题均可正常切换。
5. 推送到 fork 后，手动触发 GitHub Actions Deploy 可完成部署。
